개인정보처리방침

시행일: 2026년 8월 4일

현재 앱에는 실제 사용자 계정 기능이 없으며, 서버 기반 개인정보 수집도 없습니다.

1. 개인정보의 처리 현황

우리동네아레나는 현재 개인정보를 서버에 수집하거나 저장하지 않습니다. 방문 목록, 선택 기록, 활동력(AP), 미션 기록 및 필요한 로컬 설정은 shared_preferences를 통해 이용자의 기기 내부에만 저장됩니다.

2. Supabase 사용 현황

Supabase 의존성은 포함되어 있을 수 있으나, 현재 실제 서비스 연결을 사용하지 않으며 개인정보를 전송하거나 저장하지 않습니다.

3. 수집하지 않는 정보

광고 식별자, 위치정보, 연락처, 사진, 결제정보 및 실제 사용자 계정 정보를 현재 수집하지 않습니다.

4. 보유 및 삭제

기기 내부 기록은 앱 기능 제공을 위해 기기에 보관됩니다. 앱을 삭제하면 운영체제의 동작에 따라 로컬 저장 정보가 삭제될 수 있으며, 백업하지 않은 기록은 복구되지 않을 수 있습니다.

5. 제3자 제공 및 처리 위탁

제3자 제공이 없으며, 개인정보 관련 처리 위탁도 하지 않습니다.

6. 향후 기능 변경

향후 계정, 서버 저장, 위치정보 이용, 사진 업로드 기능이 추가되면 실제 처리 내용에 맞추어 본 방침을 갱신하고 안내하겠습니다.
